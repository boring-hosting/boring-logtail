#+title: Repository conventions migration
#+date: 2026-08-01 08:12 UTC

* Goal

Align repository coordination and project-tracking files with =AGENTS.md=
without changing application behavior.

* Scope

- Replace Make task coordination with mise tasks.
- Convert the roadmap from Markdown to Org mode.
- Convert the README from Markdown to Org mode.
- Establish the deliberately-deferred-work index required by the workflow.
- Update contributor-facing commands that are affected by the migration.

Rust and eBPF implementation changes are out of scope.

* Decisions

- Define mise tasks in =mise.toml= so task discovery and execution use the
  repository's preferred coordinator.
- Preserve the existing build, privileged run, and debug-server behaviors.
- Keep roadmap wording and checkbox state intact during the Org conversion.
- Preserve README wording, commands, and license links during its Org conversion.
- Start =TODO.org= empty apart from guidance because this migration does not
  intentionally defer work.
