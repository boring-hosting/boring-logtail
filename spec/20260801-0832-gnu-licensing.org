#+license: GFDL-1.3-or-later

* Goal

Make boring-logtail free software in the GNU/Emacs tradition: users may run,
study, share, and modify it, while copyleft prevents downstream distributors
from making the program or its derivatives proprietary.

* Scope

- License program source under GNU GPL version 3 or any later version.
- License project documentation under GNU FDL version 1.3 or any later version.
- Remove the existing MIT, Apache-2.0, and GPLv2 dual-license terms.
- Record the free-software and strong-copyleft policy in =AGENTS.md=.
- Keep the eBPF ELF license declaration GPL-compatible for the Linux verifier.

* Decisions

- Use =GPL-3.0-or-later= rather than AGPL because boring-logtail is primarily a
  distributed node agent, following the GNU Emacs model.
- Use =GFDL-1.3-or-later= with no invariant sections for Org documentation.
- Retain copyright while granting the four essential software freedoms through
  copyleft; copying and forks are welcome when recipients keep those freedoms.
- Use complete, unmodified GNU license texts and SPDX identifiers.
