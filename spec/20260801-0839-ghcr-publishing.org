* Goal

Publish boring-logtail as =ghcr.io/alfredosa/boring-logtail= and let kubernetes
pull the public image anonymously, with no registry Secret.

* Scope

- Replace GitLab Container Registry references with GHCR.
- Associate the OCI image with =github.com/alfredosa/boring-logtail=.
- Remove the obsolete =gitlab-registry= image pull Secret reference.
- Add a repeatable mise publishing task and terse operator instructions.
- Authenticate the local Docker client, build, and perform the first push.
- Make the newly created GHCR package public and verify anonymous pulling.

GitHub Actions release automation and image signing are out of scope.

* Decisions

- Use =ghcr.io/alfredosa/boring-logtail= as the canonical image name.
- Add the OCI source label so GitHub associates the package with this repository.
- Publish both an immutable Git commit tag and =latest=; deployments use the
  immutable tag when releasing and Skaffold may substitute development tags.
- Keep authentication local. Never place a PAT in the repository, shell history,
  kubernetes manifests, or documentation examples as a literal value.
- Use a classic GitHub PAT with =write:packages= for the first local push.
- Treat package visibility as a deliberate one-way operation: GHCR packages are
  private initially, and GitHub warns that Public cannot later become Private.

* First-push sequence

1. Create a classic PAT with =write:packages= only.
2. Pipe it to =docker login ghcr.io -u alfredosa --password-stdin=.
3. Build and push the commit and =latest= tags.
4. In the package settings, change visibility to Public.
5. Log out or use a clean Docker config and verify an anonymous pull.
