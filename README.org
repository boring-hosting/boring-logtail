#+title: boring-logtail
#+license: GFDL-1.3-or-later

very fast and furious eBPF log scraper, with kubernetes aware enrichment

It grabs writes on the way through the Linux kernel, rebuilds the log stream in
userspace, and figures out which kubernetes workload made the noise.

Very early. My goal is to replace Promtail. Get into Observability at root.

New to the kernel-shaped rabbit hole? Start with the
[[file:learn/README.org][friendly field guide]].

* Build it

You need stable Rust, nightly Rust with =rust-src=, and =bpf-linker=.

#+begin_src shell
rustup toolchain install stable
rustup toolchain install nightly --component rust-src
cargo install bpf-linker
mise run build
#+end_src

Cross-compiling needs the matching =${ARCH}-unknown-linux-musl= Rust target and
LLVM. On macOS, install =bpf-linker= with =--no-default-features=.

* Run it

Loading eBPF needs privileges. The mise task builds first and then gets loud:

#+begin_src shell
mise run run
#+end_src

Use =mise tasks= to see the rest. Normal =cargo check= and =cargo test= still
work.

* Throw it at kubernetes

The agent is a privileged DaemonSet because kernels tend not to let random
processes load eBPF programs. Your cluster must allow privileged workloads in
the =boring-logtail= namespace. Identity enrichment watches only Pods assigned
to the collector's node and joins their exact container IDs to the cgroup
snapshot. It does not mount or call the container-runtime socket.

Development images live at =ghcr.io/alfredosa/boring-logtail=. Push one with:

#+begin_src shell
mise run push
#+end_src

Pushing needs a local =docker login ghcr.io=. Once the GHCR package visibility
is Public, pulling needs no login and kubernetes needs no registry Secret. Start
the development loop with:

#+begin_src shell
skaffold dev
#+end_src

Skaffold builds the image, deploys =k8s/boring-logtail.yaml=, and rebuilds after
source changes. Use =skaffold delete= to remove the development resources. On a
cluster where log transport itself is noisy, avoid continuous log following:
the transported collector output can create a cross-cgroup observer loop.

Set =RUST_LOG= if you want something other than the default userspace =info=
output. Make a process write to stdout or stderr and watch it go.

Configuration stays small. Save this as =config.yaml=:

#+begin_src yaml
sampling:
  percent: 100

store:
  max_memory: 128MiB
  max_logs: 500
  retention: 1h

filters:
  namespaces:
    include:
      - game-servers

events:
  joined:
    type: info
    message: "Someone has joined!"

event_catchers:
  - regex: '(?i)\b(?:playfab )?peer connected:\s*PeerId\('
    event: joined
    emitters:
      - stdout
      - discord

event_emitters:
  stdout: {}
  discord:
    channel_id: "123456789"
    secret_from_env: WOW_MY_DISCORD_SECRET
#+end_src

Point =BORING_LOGTAIL_CONFIG= at the file and set the Discord token only if the
Discord emitter is configured:

#+begin_src shell
export BORING_LOGTAIL_CONFIG=./config.yaml
export WOW_MY_DISCORD_SECRET='your-discord-bot-token'
mise run run
#+end_src

The secret value comes from the named environment variable, never the YAML.
Event matching uses a precompiled regex set and never makes capture wait for
stdout or Discord. The stdout emitter writes one escaped line such as
=event="joined" type=info message="Someone has joined!" identity="k8s=game-servers/game-1/server ..." stream=Stdout ... log="peer connected: PeerId(123)"=.
Discord receives a compact colored embed: the configured message, the actual
caught log, namespace, Pod, container, stream, and one normal UTC timestamp.
It deliberately leaves internal IDs and sampling machinery out of the alert.

=store.retention= accepts whole seconds, minutes, or hours such as =30s=,
=15m=, and =2h=. Records age out individually; this is not a periodic
everything-must-go button.

* Cross-compile it

#+begin_src shell
cargo build --package boring-logtail --release \
  --target=${ARCH}-unknown-linux-musl \
  --config=target.${ARCH}-unknown-linux-musl.linker=\"rust-lld\"
#+end_src

The binary lands at =target/${ARCH}-unknown-linux-musl/release/boring-logtail=.
It still needs Linux to do the interesting part.
