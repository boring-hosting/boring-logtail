#+title: boring-logtail
#+license: GFDL-1.3-or-later

A small Kubernetes log tailer. It reads node-local CRI files, adds Kubernetes
identity, and throws bounded OTLP batches at =boring-collector=. The collector
stores them in Loki and serves trusted gRPC readers from that shared history.

#+begin_example
/var/log/pods -> boring-logtail -> OTLP/gRPC -> boring-collector -> Loki
                 every node                  once per cluster
#+end_example

Very early. The goal is still to replace Promtail. The eBPF version was a cool
experiment; its machinery is preserved in Git history and explained in
[[file:blog/20260816-ebpf-kubernetes-log-scraper.org][the retrospective]].

* Build it

You need stable Rust.

#+begin_src shell
mise run build
cargo test --workspace
#+end_src

* Run it

Point the agent at a CRI log tree and collector configuration:

#+begin_src shell
export BORING_LOGTAIL_CRI_ROOT=/var/log/pods
export BORING_LOGTAIL_CONFIG=./logtail.yaml
export BORING_LOGTAIL_NODE_NAME=my-node
mise run run
#+end_src

The node configuration controls bounded collector delivery. Capture limits are
deliberately internal constants.

#+begin_src yaml
collector:
  endpoint: http://boring-collector:4317
  queue_records: 1024
  queue_bytes: 8388608
  batch_records: 512
  batch_bytes: 1048576
  flush_interval_ms: 1000
  retry_max_elapsed_ms: 30000
  request_timeout_ms: 10000
#+end_src

The collector receives whole OTLP batches on =4317=, writes each batch to Loki
as one request, and keeps the existing trusted reader interface on =50051=.
It owns no in-memory history.

* Throw it at Kubernetes

#+begin_src shell
skaffold dev
#+end_src

The DaemonSet mounts =/var/log/pods= read-only and watches metadata only for its
node. It does not load kernel programs or mount tracefs, cgroups, or a container
runtime socket. Kubernetes classifies the hostPath as privileged namespace
workload even though the container itself drops every capability.
