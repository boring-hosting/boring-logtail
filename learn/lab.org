#+title: Poke it and see
#+license: GFDL-1.3-or-later

Small checks beat architectural folklore.

* Read one CRI record

On a Kubernetes node, inspect a log file without changing it:

#+begin_src shell
find /var/log/pods -type f -name '*.log' -print -quit
#+end_src

A record starts with an RFC 3339 timestamp, =stdout= or =stderr=, and =F= or
=P=. Everything after the third space is opaque payload.

* Watch append and rotation

Run the focused fixtures:

#+begin_src shell
cargo test --package boring-logtail cri::tests
#+end_src

They cover startup-at-EOF, append, new files, old-inode draining, replacement,
partial joins, malformed input, and bounds.

* Inspect the deployment

#+begin_src shell
kubectl apply --dry-run=client --filename k8s/boring-logtail.yaml
#+end_src

The node agent should mount only =/var/log/pods= plus its config. It should not
mount tracefs, host cgroups, or a runtime socket, and it should drop all Linux
capabilities.

* Visit the retired machine

The old eBPF code is still in Git history:

#+begin_src shell
git show 95e8313:blt-ebpf/src/main.rs
git show 95e8313:blt-abi/src/lib.rs
#+end_src

Read [[file:ebpf.org][the historical guide]] beside it. History is a better museum
than dead build dependencies.
