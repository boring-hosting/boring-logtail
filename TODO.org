This file indexes deliberately deferred work and ideas worth revisiting. Active
execution steps belong in the TODO section of their corresponding file under
=spec/=.

* TODO Give Kubernetes watcher tasks explicit application ownership

Why: process exit currently tears down the detached tasks, but explicit handles
would make graceful shutdown testable. See
=spec/20260816-0713-remove-ebpf-runtime.org=.

* TODO Authenticate and authorize the collector gRPC log stream

Why: the first name-selected stream is intentionally plaintext and unauthenticated;
it must stay inside trusted wiring until TLS and caller scope are decided. See
=spec/20260815-0636-collector-grpc-log-stream.org=.

* TODO Swap the web backend from Kubernetes Pod logs to the collector

Why: preserve its public =GameService.StreamLogs= and ownership check, but make
its outbound =logStreamer= call the collector with the deterministic workload
name instead of =Pods(...).GetLogs(...)=. See
=spec/20260815-0636-collector-grpc-log-stream.org= and =../web-app=.

* DONE Deploy the collector gRPC endpoint through the GitOps repository
  Why: exposed port 50051 and service wiring in =../gitops=. See
  =spec/20260815-0636-collector-grpc-log-stream.org=.

* TODO Add durable replay cursors only with persistence and acknowledgements

Why: process-local sequence numbers can make one connected replay/live handoff
gap-free, but cannot provide exactly-once reconnects or survive agent restart.
See =spec/20260809-1626-bounded-replay-log-store.org=.

* TODO Specify collector persistence and crash recovery

Why: calling the collector a database does not make bounded RAM survive a
restart; disk format, corruption handling, recovery, compaction, and cursor
durability need evidence and their own contract. See
=spec/20260813-1812-node-agent-and-cluster-collector.org=.

* TODO Specify bounded semantic multiline framing

Why: whole-record JSON recognition is safe after newline framing, but joining
stack traces or multi-line JSON changes record boundaries and memory pressure.
See =spec/20260813-1812-node-agent-and-cluster-collector.org=.

* TODO Profile the remaining node-agent heap under sustained burst traffic

Why: bounding glibc arenas cut live RSS from 55--58 MiB to 33--34 MiB, but a
heap profile should attribute the remaining roughly 25 MiB anonymous RSS
before further tuning. See
=spec/20260813-1812-node-agent-and-cluster-collector.org=.

* TODO Design event message capture interpolation

Why: ={1}= looks tiny but needs honest missing-group, escaping, byte-to-text,
and secret-leak semantics. Static messages ship first. See
=spec/20260812-1405-lean-config-event-catchers.org=.

* TODO Allow several destinations of one emitter kind

Why: the lean key-selected configuration supports one stdout and one Discord
destination today; do not invent nesting until a real second destination is
needed. See =spec/20260812-1405-lean-config-event-catchers.org=.
